What this beta tests
  • Same-origin DOM access — can the beta page read the player document without a SecurityError?
  • Popup interception — can window.open(), target="_blank" and programmatic navigation be stubbed so no advertising tab opens?
  • Ad filtering — modular, conservative DOM rules under /beta/ad-filter.
  • Playback integrity — play / pause / seek / volume / fullscreen / PiP / keyboard and progress must keep working.
  • If the proxy is rejected or impossible, the beta falls back to the normal direct embed and explains why.
